# Skills

Reference documents that define patterns, practices, and methodologies for working in this
codebase. Skills are the source of truth for code style and development workflow.

> **Attribution:** These skills were borrowed from
> [citypaul/.dotfiles](https://github.com/citypaul/.dotfiles) and adapted to the JSHACK.ME
> project's domain.

## Available Skills

| Skill                    | Purpose                                                                     |
| ------------------------ | --------------------------------------------------------------------------- |
| **expectations**         | Working expectations and documentation practices                            |
| **functional**           | Functional programming patterns — immutability, pure functions, composition |
| **planning**             | Planning work in small, known-good increments                               |
| **react-testing**        | React component testing with Vitest Browser Mode and Testing Library        |
| **refactoring**          | When and how to refactor after tests pass                                   |
| **tdd**                  | Test-Driven Development workflow — RED-GREEN-REFACTOR cycle                 |
| **test-design-reviewer** | Evaluates test quality using Dave Farley's 8 properties                     |
| **testing**              | Behavior-driven testing patterns and test factories                         |
| **typescript-strict**    | TypeScript strict mode — no `any`, schema-first, branded types              |

## Skill Hierarchy

1. **Foundation:** `functional` + `typescript-strict` (core code style)
2. **Development:** `tdd` + `testing` + `react-testing` (how to write code)
3. **Quality:** `refactoring` + `test-design-reviewer` + `expectations` (ensuring quality)
4. **Organization:** `planning` (structuring work)
